# EEG Motor Imagery Classification

Motor imagery EEG sinyallerinden, kişi-bağımsız bir modelle hangi hareketin
(el/ayak) hayal edildiğini tahmin etmeye çalışan bir proje.

## Veri seti
PhysioNet EEG Motor Movement/Imagery Dataset (MNE-Python üzerinden erişiliyor)

## Durum
İlk CSP + LDA baseline modeli çalışıyor (~%62 doğruluk, deneme1 üzerinde).
